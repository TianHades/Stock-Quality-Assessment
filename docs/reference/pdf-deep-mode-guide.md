# 深度模式操作指引（PDF 类排雷规则）

> 来源：原 `financial-report-minesweeper` 的 `skill/SKILL.md` Phase 2 与
> `skill/download-report.md`（已并入本工程，见 [minesweeper-provenance.md](minesweeper-provenance.md)）。
> 本文档描述本工程 Python pipeline 中的确定性实现方式，供维护者与人工复核使用。

## 1. 定位

快筛（默认）只使用 tushare 结构化数据；深度模式按需下载并解析**年报 PDF**，补齐
7 条依赖非结构化信息的规则，并做 5.8 的 PDF 补充检查：

| 规则 | 内容 | 年报中的位置（关键词） | 判定方式 |
|------|------|----------------------|---------|
| 1.3 | 运费增长 << 收入增长 | 销售费用/营业成本（含成本构成表）附注：运输费、运费、装卸费 | 数值自动：提取本期/上期金额算增速 |
| 5.3 | 财务总监频繁更换 | 董事、监事、高级管理人员变动：财务总监、财务负责人、首席财务官 | 证据 + WARN/待复核 |
| 5.4 | 独立董事辞职 | 同上：独立董事 + 辞职/辞任/辞去（排除换届/任期届满） | 证据 + WARN/待复核 |
| 5.5 | 客户集中度 | 前五名客户/前五大客户销售额占比 | 数值自动：合计 >50% WARN、单一 >50% FAIL |
| 5.6 | 跨行业频繁收购 | 董事会报告「投资状况分析」：收购、跨行业、跨界 | 证据 + 待复核 |
| 5.8 | 其他应收款异常（补充） | 「非经营性占用」段：适用/不适用 | 命中“适用”→ FAIL |
| 5.9 | 监管处罚/立案调查 | 全文：立案、警示函、处罚决定、监管措施、行政处罚、纪律处分、通报批评、公开谴责、留置、被调查等 | 立案→FAIL；警示函/处罚/留置→WARN |
| 6.2 | 研发资本化比例 | 研发投入附注：研发投入资本化、资本化的比重 | 数值自动：>50% FAIL、>30% WARN |

## 2. 使用方式

```bash
# 自动从巨潮资讯网检索并下载最近年报（A 股）
sqa minesweeper 600519 --mode deep
sqa analyze 600519 --deep

# 离线/指定 PDF（推荐用于网络受限或已下载年报）
sqa minesweeper 600519 --mode deep --pdf "D:\reports\600519_年报_2025.pdf"
sqa analyze 600519 --deep --pdf "...\600519_年报_2025.pdf"

# 指定 PDF 链接（仅支持 cninfo.com.cn / stockn.xueqiu.com / 10jqka.com.cn）
sqa minesweeper 600519 --mode deep --pdf-url "https://static.cninfo.com.cn/..."
```

输出：`--json` 中的 `deep` 字段包含 PDF 来源/页数/解析后端、每条 PDF 规则的判定
（`verdicts`）与证据片段（`evidence`，含页码与原文摘录）；失败时 `deep.status` 为
`skipped`（无 PDF）或 `error`（解析失败），并保留快筛结果不中断流水线。

## 3. 实现链路

```
resolve_pdf（本地路径 → 指定 URL → 巨潮搜索）
  → extract_pdf（pdftotext -layout 优先，pypdf 回退；文本缓存按 sha1）
  → extract（按关键词/表格抽取证据：金额、百分比、上下文片段）
  → rules（数值型自动判定；判断型保守给 WARN/SKIP + 证据）
  → 替换快筛中对应规则的 SKIP 占位，重新计分与闸门判定
```

模块位置：`src/sqa/minesweeper/deep/`（`pdf_download.py` / `pdf_text.py` /
`extract.py` / `rules.py` / `pipeline.py`）。

## 4. 安装依赖

```bash
pip install -e ".[pdf]"     # 安装 pypdf（纯 Python，BSD）
# 可选：安装 poppler 提供 pdftotext（抽取质量更好，尤其表格版式）
```

未安装 pypdf 且无 pdftotext 时，深度模式返回 `error` 并提示，不影响快筛。

## 5. 判定策略（重要）

- **数值型规则**（1.3 / 5.5 / 6.2 / 5.8 补充）在证据可靠时自动判定；证据不足
  （未披露、金额提不出、区间未定义）一律 `SKIP` 并写明原因，不猜测。
  - 1.3 只在**同一表格行**取本期/上期金额，下一行出现中文项目名即拒绝（防止把
    相邻项目的金额误当上期）；纯数字续行才允许拼接。**2026-10-25 复核修正**：
    命中片段必须处于"销售费用/营业成本/管理费用/附注"语境且不得来自关联方交易表
    （松发 603268 曾误取"恒力海运运输费"）；营收同比 >100%（借壳/并表阶跃）→ SKIP。
  - 5.5 在关键词页 + 下一页继续找"前五名客户合计"与"第一名"明细；"总额"限定在
    客户/销售语境，避免误取供应商"采购总额"。
  - 6.2 优先用"资本化金额 ÷ 研发投入合计"做除法；百分比只接受紧邻
    "资本化(的)比重/比例/率"且后接**唯一**数值的表头版式，多列相邻值视为列错位放弃。
  - 5.8 只认勾选项：`√适用` → found（覆盖 5.8 为 FAIL）；`√不适用/否/不存在` → clear；
    未勾选项中的"不适用"不再提前清空，普通语句"适用于…"也不误报。
  - **5.2 补充（2026-10-25）**：年报"前十名股东"脚注明确披露大股东持股减少系
    **无偿划转 / 可交换债换股**且与"持股减少"同段出现 → 覆盖快筛 5.2 为 PASS
    （长江电力 600900 案例：稀释+划转+EB 换股，8.78pp 比例下降无二级市场减持）。
- **判断型规则**（5.3 / 5.4 / 5.6 / 5.9）按句/表格行检出：同句或关键词附近窄窗口
  出现辞职/辞任/聘任等变动词（5.4 只认辞职/辞任/辞去并排除换届）；5.4 检出 ≥2 处独董辞职 → `FAIL`（对齐上游），
  2026-10-25 起只认"辞职/辞任/辞去"并按（页, 句）去重、排除换届/任期届满语境
  （松发 603268 借壳后提前换届+同日新聘不再误报集体辞职）；
  5.9 解析"√是/√否"勾选项与按句否定语境（"公司是否被立案调查：□是 √否"不报、
  "公司不存在…；控股股东被立案"仍报），并将"留置/被调查/受到处罚/涉嫌违法违规"
  纳入关键词；一般性环保罚款/合规整改按上游 C 类 PASS。
  2026-10-25 复核重写 5.9 抽取：PDF 硬换行先还原为语义块（否定句/标题跨行不再丢
  语境）、否定窗口 8→40 字符并支持"不存在……的情形"全句否定、承诺函/补偿条款/
  风险提示/表格字段/章节模板标题守卫；`√适用` 后真实事实（如茅台"高管被实施留置"）
  保留 WARN。全页扫描不再受 `max_hits` 截断。
- 上游原实现由 LLM 阅读全文判断；本工程是确定性启发式，**上限低于 LLM**，因此对
  判断型规则采用"宁漏勿错 + 证据留痕"；`deep.evidence` 按 fails → warns → hits
  优先级输出，便于人工复核。

## 6. 已知限制

1. 扫描版/图片型 PDF 无文本层 → 抽取为空，deep 返回 `error`（不做 OCR）；
   文本量过少（<500 字符）或**非空页占比 <10%** 也会被判为抽取失败，避免只抽到
   封面/页眉时给 5.9 等规则假 PASS；
2. 巨潮搜索依赖外网与页面接口，接口变动或网络受限时请用 `--pdf` 指定本地文件；
   已有缓存会优先复用，`--refresh` 时重新下载、失败再回退缓存；
3. 年报表格版式差异大，金额抽取可能失败（如运输费并入营业成本不单列、跨页拆列）
   → SKIP；6.2 的多列表头无法确认列归属时也会放弃；
4. PDF 路径为目录/无权限、缓存目录不可写等文件系统异常会降级为 `error`，不会
   抛异常击穿排雷主流程；
5. `--pdf/--pdf-url` 必须配合 `--mode deep`（minesweeper）或 `--deep`（analyze），
   否则 CLI 直接报参数错误；
6. PDF 文本缓存位于 `data_cache/pdf_text/`、下载文件位于 `data_cache/pdf/`（均已 gitignore），
   可整目录删除重取。
