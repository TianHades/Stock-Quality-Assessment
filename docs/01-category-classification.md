# 01 · 股票类别判定规则（Category Classification）

> StockQualityAnalysis 规则文档 · 第 1 篇
> 上游：无（本判定是分析 pipeline 的入口环节之一）
> 下游：02-排雷规则（规则源自 financial-report-minesweeper，已内联）、03-质量权重表、04-专属分析模块（已实现）

---

## 0. 文档目的

输入一只 A 股，输出它的**类别标签组合**，用于后续索引对应的权重表与专属分析模块。

**本文档只解决"这是什么类型的股票"，不评估好坏。**

## 1. 分类模型：一个主风格 + 两个附加维度

最初的"六类互斥"设计无法表达真实市场（中国神华 = 周期 + 红利，长江电力 = 价值/均衡 + 红利），
修正为三维标签模型：

| 维度 | 取值 | 性质 | 用途 |
|------|------|------|------|
| **主风格** | 成长 / 价值 / 周期 / 均衡 | 互斥，必选其一 | 索引质量评分权重表（03） |
| **附加标签** | 红利 | 可叠加、可选 | 追加红利专属分析模块 |
| **行业标签** | 消费 / 科技 / 其他 | 可叠加 | 追加行业专属分析模块 |

关于"均衡"：成长与价值之外的兜底主风格（增速中等且估值分位中等，大量消费白马、制造业
龙头落在此类）。强行二分会误导分析，故单列；其权重表取成长与价值两套的均值（见 03，待定）。

**典型输出示例**：

| 股票 | 主风格 | 附加标签 | 行业标签 |
|------|--------|---------|---------|
| 中国神华 | 周期 | 红利 | 其他 |
| 长江电力 | 价值/均衡 | 红利 | 其他 |
| 贵州茅台 | 成长/均衡 | — | 消费 |
| 宁德时代 | 成长 | — | 科技 |
| 京东方 A | 周期 | — | 科技 |

## 2. 前置排除（第 0 步，命中即终止）

以下类别不在本系统范围内（2026-09 项目启动时与使用者确认的范围）：

| 排除项 | 识别方式 | 排除原因 |
|--------|---------|---------|
| ST / *ST / 退市风险 | 证券简称含 ST，或触发交易类退市风险 | 质地分析退化为纯排雷，无常规分析意义 |
| 医药生物（全产业链） | 申万一级行业 = 医药生物 | 分子行业逻辑差异过大（创新药管线 / 集采 / CXO 订单），需独立框架；词表含“中成药/成药”等复合词（2026-10 校准，避免“中成药”不含“中药”子串漏网） |
| 银行 / 非银金融 | 申万一级行业 = 银行、非银金融 | 报表体系不同（不良率 / EV / NIM），常规财务比率失效 |

命中 → 输出 `OUT_OF_SCOPE`，分析终止。

## 3. 判定顺序及理由

```
周期性 → 红利属性 → 成长/价值/均衡 → 行业标签（独立并行）
```

**为什么是这个顺序**：

1. **周期性最先**：周期股会同时污染后续所有判定——周期底部低 PB（假价值）、底部增速下滑
   （假衰退）、景气顶部高增速（假成长，如万华化学景气顶部营收 CAGR 可超 50%）、顶部特别
   分红（假红利）。静水 `super-growth-quality-checklist` 的"先判周期股防误杀"护栏验证了
   这一优先级设计。
2. **红利属性第二**：判定标准全部是客观硬数据（股息率、连续性、派息率、FCF 覆盖），先锚定
   这个可叠加标签，不干扰主风格判定。
3. **成长/价值最后**：两者边界最模糊，依赖增速与估值分位的组合判断，放在信息最全的位置。
4. **行业标签独立**：纯行业映射，不参与风格竞争，可与任何结果组合。

**在整体 pipeline 中的位置**（见 02 号文档 §4 与 `src/sqa/analyze.py`）：

```
指标计算 → 通用排雷(一票否决) → 【本文档：类别判定】 → 加权质量评分 → 专属分析 → 估值 → 报告
```

排雷在分类之前（排雷不依赖类别）；本文档的第 0 步"范围排除"与排雷相互独立。

## 4. 判定流程总图

```
股票代码
  │
  ▼
[0] 范围排除（ST/医药/金融）──命中──→ OUT_OF_SCOPE（终止）
  │ 通过
  ▼
[1] 周期性判定 ──────────命中──→ 主风格 = 周期 ─────────────┐
  │ 未命中                                                │
  ▼                                                       │
[2] 红利属性判定 ────────命中──→ 附加标签 += 红利           │
  │ （无论命中与否，继续判主风格）                           │
  ▼                                                       │
[3] 成长 / 价值 / 均衡判定 → 主风格 = 成长 / 价值 / 均衡      │
  │                                                       │
  ▼                                                       ▼
[4] 行业标签映射 → 消费 / 科技 / 其他
  │
  ▼
输出 { 主风格, 附加标签, 行业标签, 置信度, 证据 } → 索引权重表 + 模块清单
```

## 5. 规则明细

### 5.0 阈值配置表（所有可调参数集中于此，禁止散落硬编码）

| 参数 | 默认值 | 用于规则 | 调整说明 |
|------|--------|---------|---------|
| `CYCLE_GM_RANGE` | 10 pp | R2 | 近 10 年毛利率最大极差 |
| `CYCLE_NP_DRAWDOWN` | 50% | R2 | 近 10 年归母净利润最大回撤（先峰后谷） |
| `DIV_YIELD_FLOOR` | 3.0% | D1 | 股息率静态下限 |
| `DIV_YIELD_RISK_FREE_SPREAD` | 1.5 pp | D1 | 相对 10Y 国债的动态溢价 |
| `DIV_CONSECUTIVE_YEARS` | 5 | D2 | 连续分红年数 |
| `DIV_PAYOUT_MIN` | 25% | D3 | 派息率下限（意愿） |
| `DIV_PAYOUT_WARN` | 90% | D3 | 派息率可持续性警戒线 |
| `DIV_FCF_COVER_MAX` | 100% | D4 | 近 3 年累计分红 / 累计 FCF 上限 |
| `GROWTH_REV_CAGR` | 15% | G1 | 营收 3 年 CAGR 门槛 |
| `GROWTH_NP_CAGR` | 20% | G1 | 扣非净利 3 年 CAGR 门槛 |
| `VALUE_PCTL` | 30% | V1 | PE/PB 自身近 5 年分位数门槛 |
| `VALUE_REV_CAGR_MAX` | 10% | V1 | 价值类营收增速上限 |
| `VAL_PCTL_WINDOW` | 5 年 | V1 | 估值分位回看窗口 |

### 5.1 [1] 周期性判定

**R1 · 行业清单（硬映射，精确到申万二级/细分概念，一级不够用）**

主营业务属于以下清单 → 周期，置信度高：

```
钢铁（普钢/特钢）          有色金属（采掘/冶炼/加工，锂钴稀土等资源品）
煤炭开采                  基础化工（石化/化纤/氟化工/磷化工/钛白粉/纯碱/农药）
石油石化                  航运港口、造船
工程机械                  建材（水泥/玻璃/玻纤）
面板（LCD/OLED 面板制造）   存储芯片（DRAM/NAND 制造与模组）
养殖（生猪/肉鸡/水产）      房地产开发
```

注意清单中的"面板、存储、养殖"分别截胡了行业标签"科技、科技、消费"——周期判定先于
行业标签执行，截胡是设计内行为。

**R2 · 量化特征（捕获清单外的隐形周期）**

行业不在 R1 清单，但**同时满足**以下两条 → 周期，置信度中（建议人工复核）：

- 近 10 年毛利率极差 > `CYCLE_GM_RANGE`（10 pp）
- 近 10 年归母净利润**最大回撤**（先峰后谷）> `CYCLE_NP_DRAWDOWN`（50%）

> **2026-10 校准修订**：原判据为"峰谷比 > 3 或出现过亏损"，金标准实测把宁德时代
> 误判为周期（10 年利润涨 25 倍 + 毛利率中枢从 38% 降至 17%，峰谷比 25 倍）。
> 峰谷比无法区分"从高点跌落"（周期）与"从低基数长大"（成长），改为最大回撤口径后
> 单调成长公司不再误触发；盈利转亏损（如牧原 2024）自然落入回撤 100%。
> 同口径下京东方（2017→2019 回撤 75%）正确命中。

**主营判定规则**（R1/R2 的输入）：

- 取最新年报主营业务构成；
- 单一业务收入占比 > 50% → 按该业务判定；
- 否则计算周期类业务收入合计占比，> 50% → 判周期（适用综合集团）；
- 构成巨变（第一大业务易主）→ 标注 `transition`，置信度降级。

### 5.2 [2] 红利属性判定

四条全部满足（AND 逻辑）→ 附加标签 `红利`：

| # | 规则 | 判定 |
|---|------|------|
| D1 | 股息率：近 3 年平均股息率 ≥ max(`DIV_YIELD_FLOOR`, 10Y 国债 + `DIV_YIELD_RISK_FREE_SPREAD`) | 硬标准 |
| D2 | 连续性：连续分红年数 ≥ `DIV_CONSECUTIVE_YEARS`（每年均有现金分红） | 硬标准 |
| D3 | 意愿与可持续：近 3 年平均派息率 ∈ [25%, 90%] | 25%~90% = HIT；90%~100% = HIT + WARN；<25% 或 >100% = MISS |
| D4 | 分红能力：近 3 年累计分红 / 近 3 年累计自由现金流 ≤ `DIV_FCF_COVER_MAX` | FCF 为负时直接 MISS |

说明：

- D3 的 90% 警戒线用于过滤"特别分红"与"借钱分红"（周期顶部的高分红天然不可持续）；
- D4 保证分红来自真实现金创造，而非融资性现金；
- D1 用 3 年均值而非单点，平滑周期波动。

### 5.3 [3] 成长 / 价值 / 均衡判定（仅对非周期股）

按顺序判定，先命中先归属：

**G1 · 成长**（扣非口径防止一次性收益虚增）：

```
近 3 年营收 CAGR ≥ 15%  或  近 3 年扣非净利 CAGR ≥ 20%  →  成长
```

**V1 · 价值**：

```
（PE 或 PB 处于自身近 5 年分位 < 30% 或 所处行业分位 < 30%）
且 近 3 年营收 CAGR < 10%
→ 价值
```

**E1 · 均衡**：以上均未命中 → 均衡。

补充信号（不改变主风格，写入 `signals` 供报告引用）：

- 成长股同时命中低估值分位 → `signals += ["low_valuation_percentile"]`（成长 + 便宜，
  值得在报告中高亮）；
- 亏损股（PE 无意义）→ 估值分位退化为仅用 PB；双缺 → 估值分位 SKIP，主风格按增速单判。

### 5.4 [4] 行业标签映射（申万一级 → 标签）

| 行业标签 | 申万一级行业 | 备注 |
|---------|-------------|------|
| 消费 | 食品饮料、家用电器、纺织服饰、商贸零售、社会服务、美容护理、轻工制造、农林牧渔 | 养殖已被 R1 截胡为周期 |
| 科技 | 电子、计算机、通信、传媒、电力设备、国防军工、机械设备 | 面板/存储/工程机械已被 R1 截胡 |
| 其他 | 其余全部 | 建筑装饰、公用事业、交通运输、环保等 |

> **实现层校准注记（2026-10）**：实际实现按数据商行业字符串（tushare `industry`）
> 做关键词匹配，粒度介于申万一级与二级之间。金标准实测的复合词陷阱：
> "家用电器"不含子串"家电"、"元器件"不含"元件"、"电信运营"不含"通信"——
> 词表须同时收录整词与子词。另：牧原的行业串是"农业综合"（不含养殖关键词），
> R1 未命中、由 R2 量化特征兜底判周期，符合设计（R2 的存在意义）。
> 2026-10-19 词表校准：宽词"服务"不再抢走"软件服务/汽车服务"；补"乳制品/红黄酒/
> 林业/日用化工/文教休闲/批发"等消费串，以及"互联网/机床/仪表/软件"等科技串；
> 强科技/工业词（机械/设备/仪表/软件/互联网等）优先于消费词判断。R1 补
> "水运/渔业/塑料/橡胶/染料/焦炭"，"日用化工"显式白名单排除（化妆品消费）。

## 6. 边角案例处理

| 案例 | 处理方式 |
|------|---------|
| 周期 + 红利（神华、陕煤） | 合法组合：权重表用周期，追加红利模块；估值用 PB 分位 + 股息率双验证 |
| 上市 < 5 年（D2 数据不足） | D2 退化为"上市以来每年分红"；整体置信度 = 低 |
| 上市 < 3 年（CAGR 不足） | G1/V1 数据不足 → 主风格按行业默认（科技 → 成长，消费 → 均衡），置信度 = 低 |
| 转型公司 | 用最新年报主营构成；第一大业务易主 → 标注 `transition`，置信度 = 低 |
| 综合集团 | 周期类收入占比 > 50% 才判周期；否则按第一大业务，置信度 = 中 |
| 周期顶部假成长 | R1 行业清单优先级高于 G1，天然拦截（万华化学景气顶部 CAGR 50%+ 仍判周期） |
| 周期顶部假红利 | D3 派息率区间 + D4 FCF 覆盖自然过滤；周期股的红利标签报告强制附"分红随周期波动"警示 |
| 双主業冲突（如消费 + 科技） | 不冲突：行业标签可叠加，主风格仍单选 |

### 校准记录（2026-10-06 首次真实数据验证）

首轮 6/13 → 修复后 13/13。暴露并修复的问题（全部已沉淀为代码注释与回归测试）：

1. **单季报表污染**：income/fina_indicator 不滤 report_type 会取到 Q4 单季值
   （神华年度 EPS 3.0 被读成单季 0.6 → 派息率 178%）；
2. **分红三倍虚增**：`cash_div=0.0 or cash_div_tax` 的 falsy 回退让预案/送转/实施
   三行各计一次税前金额（神华 2024 全年 2.26 被算成 6.78）；
3. **中期分红漏计**：原口径只取 end_date=12 月的记录，漏掉中期分红
   （神华 2025 = 中期 0.98 + 年度 1.03）；
4. **FCF 字段口径**：tushare cashflow 无 `buy_fixed_assets_oth`，优先 `free_cashflow`，
