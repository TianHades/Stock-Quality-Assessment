## 0. 定位

质量评分（03）是**通用体检**——六维度每只股票都查，权重不同。专属模块是
**专科检查**——只对特定类型成立的"关键变量状态"问题：

- 通用评分回答"质地多好"；模块回答"这类股票的关键变量现在处于什么状态"。
- 模块输出包含**对质量评分的修正意见**（如周期底部财务分低是买点信号而非减分项）。

| 模块 | 触发条件（01 输出） | 回答的问题 |
|------|-------------------|-----------|
| `cycle_position` | 主风格 = cyclical | 现在处于周期哪个阶段 |
| `dividend_sustainability` | 附加标签含 dividend | 分红还能持续多久 |
| `growth_quality_check` | 主风格 = growth | 增长是真的而且能持续吗 |
| `moat_check` | 行业标签 = consumer 或 主风格 ∈ {value, balanced} | 优势守得住吗 |

实现原则沿用全系统约定：**能算的量化，算不出的做成结构化检查清单**
（状态 `pending`，供人工/LLM 深度模式补充判断），绝不硬造。

## 1. cycle_position · 周期位置判定

### 1.1 量化信号（数据管道已就绪）

| 信号 | 口径 | 判读 |
|------|------|------|
| S-capex | CAPEX/折旧摊销（购建长期资产现金 ÷ 折旧） | <1.5 底部/出清区（肖璟阈值）；1.5-2.5 中性；>2.5 产能激增 |
| S-profit | 最新归母净利在 10 年序列中的分位 | 低分位=底部特征；高分位=景气高位 |
| S-margin | 最新毛利率在 10 年序列中的分位 | 与 S-profit 互证 |
| S-inv | 存货周转率同比变化 | 改善=去库存完成（底部右侧信号） |
| S-cip | 在建工程同比 | 高增=产能建设期（下一轮供给的领先指标） |

### 1.2 位置判定规则

```
profit_pctl ≤ 30%           → bottom    底部区域
profit_pctl ≥ 70%           → peak      景气高位
profit_pctl 中间 & 同比 > 0  → recovery  复苏上行
profit_pctl 中间 & 同比 ≤ 0  → downturn  景气回落
```

置信度：profit 与 margin 分位同向（均 <35% 或均 >65%）→ high，否则 medium。
折旧字段缺失时 S-capex 降级 SKIP（位置判定不受影响）。

### 1.3 对质量评分的修正意见

| 位置 | 意见 |
|------|------|
| bottom | 盈利分受周期压制属预期内；健康/现金流权重已最高，高分=优质周期底（神华型） |
| peak | 盈利能力分含景气溢价，跨周期评估需打折；警惕高 CAPEX 埋下下一轮过剩 |
| recovery | 左侧确认中，关注库存去化与提价持续性 |
| downturn | 景气自高位回落，规避盈利下修风险 |

方法论来源：`../Industry-analysis/capacity-cycle-judgment`（产能周期四阶段 +
CAPEX/折旧 <1.5 底部信号），产品价格分位等另需行业数据库的信号列入检查清单。

## 2. dividend_sustainability · 分红持续性

### 2.1 量化信号

| 信号 | 口径 | 判读 |
|------|------|------|
| C-cover | 近 3 个财年各年 FCF/当年分红金额 | <1 靠存量现金/融资维持 |
| C-payout | 近 5 年派息率序列 | 稳定带（30-90%）=政策性分红；波动大=盈余管理 |
| C-streak | 连续分红年数（复用 01 的 D2 口径） | — |
| C-yield | 最新股息率相对动态阈值的余量 | 余量薄=股价已定价分红 |

### 2.2 判定

```
at_risk     : 最新覆盖 <1.0 或 最新派息率 >100%
watch       : 覆盖 1.0-1.2，或覆盖率连续两年走弱，或近5年派息率峰值 >90%，
              或最新派息率不在 20-90%，或覆盖/派息数据缺失
sustainable : 覆盖 ≥1.2 且派息率 20-90% 且 streak ≥5 且峰值 ≤90%
```

> 2026-10-19 校准：走弱改为"2025<2024<2023"的连续下降；派息率窗口 3→5 年；
> sustainable 增加 20–90% 派息率与缺失数据校验（不再默认 sustainable）。

主风格 = cyclical 时强制附加："分红随周期波动，景气顶部的高分红不可线性外推"。

## 3. growth_quality_check · 成长质量校验

### 3.1 量化信号

| 信号 | 口径 | 锚点 0/50/100 |
|------|------|--------------|
| G-vol | 近 5 年营收增速的标准差 | ≥0.30 / 0.15 / ≤0.05（越稳越真） |
| G-sync | 扣非 CAGR − 营收 CAGR（pp） | -15 / +5 / +15（利润略快=经营杠杆） |
| G-trend | 最新同比 − 3年CAGR（pp） | -15 / 0 / +10 |
| G-quality | 应收增速 − 营收增速（pp） | +20 / 0 / -5 |

注意：G-sync > +30pp 时标注"查一次性收益/减值转回"，不加分。

### 3.2 定性检查清单（静水 super-growth-quality-checklist 蒸馏）

**正向三看**（按流派二选一核对）：
- 长线价投视角：① 垄断性（独占何种生产要素/关系）② 定价权（提价不流失客户）③ 持续性（优势多久）
- 景气价投视角：① 宏观稳定性 ② 行业天花板（渗透率/空间）③ 业绩增速确定性

**反面证法**（芒格反过来想，四特征任一命中即警示）：
① 业绩增速持续下滑 ② 股价持续创新低 ③ 产品/服务竞争力变差 ④ 行业结构性衰退

### 3.3 判定

量化均分 ≥75 → `solid`；45-75 → `acceptable`；<45 → `poor`（附"增长真实性存疑"）。

## 4. moat_check · 护城河检查

### 4.1 量化信号（代理指标）

| 信号 | 口径 | 锚点 0/50/100 |
|------|------|--------------|
| M-rel | 最新毛利率 − 同行中位数（pp） | -15 / 0 / +15 |
| M-roic | 10 年 ROIC 中位数 | 3 / 7 / 15（%） |
| M-stab | 10 年 ROIC 标准差 | ≥10 / 5 / ≤2 |
| M-trend | 毛利率 10 年变化（首末差 pp） | -15 / 0 / +10 |

侵蚀警示：M-trend < -5pp 且 M-rel < 0 → `eroding`。

### 4.2 定性检查清单（肖璟《如何快速了解一个行业》护城河五类型）

| 类型 | 识别问题 |
|------|---------|
| 资源垄断 | 是否独占某种生产要素（矿权/牌照/区位）？ |
| 网络效应 | 用户增加是否让产品对每个用户更有价值？ |
| 转换成本 | 客户换供应商的成本有多高（数据/流程/学习）？ |
| 规模经济 | 单位成本是否随规模显著下降？对手砸钱能否绕开？ |
| 品牌溢价 | 同样的东西能否卖得更贵还卖得动？ |

注意（上游方法论约束）：导入期行业谈护城河为时过早、衰退期护城河正在瓦解——
本清单适用于成熟期行业，由检查清单状态项标注。

## 6. 实现状态（2026-10-19）

四模块已代码化（`src/sqa/modules/`），量化信号全自动，定性清单以 `pending`
状态输出，经 `sqa analyze` 串联。实跑校准记录：

- **神华（cyclical+红利）**：质量分 A+（94.2），但分红持续性判定 `at_risk`——
  最新财年 FCF/分红覆盖仅 0.72（资本开支上升 + 煤价下行），而 D4 的 3 年累计
  口径 0.97 掩盖了最新一年的恶化。**模块层的最新年度镜头捕捉到了评分层平滑
  窗口漏掉的拐点**——这是 04 层存在的核心价值案例；周期位置判"景气高位"，
  S-capex 2.27（中性偏建设）与此互证；
- **茅台（3 年窗口后 balanced+consumer）**：不再触发 `growth_quality_check`；
  护城河 81.2/strong（ROIC 中位数高 + 毛利率大幅领先同行中位）；分红持续性
  `watch`（2024 年 FCF 覆盖 0.71、2025 回升至 1.13）；
- **京东方（cyclical+tech）**：周期位置"景气高位/medium"——profit 与 margin
  分位未同向（不达 high 置信）；S-capex 1.07（底部/出清区）与价格高位形成
  背离，检查清单中的产品价格分位项留给人工复核。

实现注记：S-capex 使用 `c_pay_acq_const_fiolta` / `depr_fa_coga_dpba`
（2026-10 字段校准），字段缺失时降级 SKIP；分红持续性同时输出分年覆盖序列
（`fcf_coverage_by_year`）供趋势研判，不只看最新值。

## 7. 开放问题

1. 折旧字段在 tushare cashflow 的字段名不稳定，多候选缺失时 S-capex 降级 SKIP；
2. 产品价格分位/库存绝对水位需行业级数据库（百川/卓创类），列入清单待接；
3. 定性清单的 LLM 自动化判断属于深度模式（同排雷深度模式一并规划）；
4. M-rel 依赖同行中位数管道，同行缺失时降级 SKIP。
